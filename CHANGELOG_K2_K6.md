# K2–K6 changelog

- Raised kernel version to 0.3.0.
- Added Kernel Profile 1.0 boot diagnostics.
- Added capability lifecycle operations with attenuation.
- Converted endpoint queues from raw thread IDs to generation-safe references.
- Added blocked-fault state and synchronous pager IPC.
- Added root bootinfo and initial authority description.
- Added scheduling-context, frame, page-table, notification and IRQ objects.
- Added ARM64 page map/unmap primitives and W^X policy.
- Added integrated profile self-tests.
