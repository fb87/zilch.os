# Roadmap

1. Dual-target boot and stable contracts.
2. Exception entry, timers, interrupt controllers, physical memory discovery.
3. Threads, scheduler, IPC, capabilities, address spaces.
4. User-space root task, pager, resource manager, drivers.
5. SMP and real-time scheduling.
6. ARM stage-2 and AMD64 EPT/VMX/SVM virtualization mechanisms.
7. Safety hardening, coverage, formal verification, certification evidence.
