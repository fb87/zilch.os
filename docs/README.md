# Zilch documentation

This directory is the canonical home for project documentation.

- `architecture/` — current architecture, ABI, and alignment decisions.
- `readiness/` — authoritative production-readiness and evidence tracking.
- `roadmap/` — active implementation order and program checklist.
- `certification/` — current certification procedures and focused probes.
- `history/` — completed batches, retired profiles, fixes, and historical records.

Module-local design notes remain next to their implementation under `src/`.
The repository root intentionally contains only entry-point project files such as
`docs/README.md`, `CHANGELOG.md`, and the build configuration.
